#### This is the repository for a Master's project of Kendig Sham and Junkai Yang:
### Inferring cell state from gene expression data using tractable deep probabilistic models
##### Abstract:
Single-cell RNA sequencing (scRNA-seq) has led to the discovery of novel cell types, and functional cell states and allows for a deeper understanding of molecular changes in complex biological systems, particularly in cancer, immunology, and developmental biology. Conventional analysis typically involves clustering cells in the low-dimensional transcriptome space, which was shown to be problematic. A recent study instead proposed using higher-order expression dependencies to infer cell types, sub-types, and states. Although computationally expensive, it recapitulates the cell annotations from other methods as well as revealing the transcriptomic dynamics at a higher resolution. Here, we examine the feasibility of leveraging a deep probabilistic model called probabilistic circuits (PCs) to scale up the inference of higher-order expression dependencies. We show that PCs can efficiently learn the joint distribution of the high-dimensional scRNA-seq data and perform exact inference tractably. Then we assess the feasibility of computing higher-order expression dependencies using the inferences.
